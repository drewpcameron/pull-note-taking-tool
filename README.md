# PULL Notes

A minimal sales call note-taking app built around the [PULL framework](https://thephysicsofstartups.substack.com/p/the-pull-framework-in-detail).

**Project · Urgency · List of Options · Limitations**

## Features

- Four free-form sections, one per PULL element
- Auto-saves to browser localStorage — notes persist across sessions
- Sidebar for switching between saved calls
- Copy notes to clipboard or download as a Markdown file

## Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to **Deploy from a branch**, branch `main`, folder `/ (root)`
4. Save — your app will be live at `https://<username>.github.io/<repo-name>/`

No build step needed. It's a single HTML file.
